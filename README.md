# Act_3.1-Arbol-Binario
El proyecto consiste en diseñar una interfaz gráfica para administrar empleados y representar las operaciones principales de esta estructura de datos.

# Objetivo
Comprender el funcionamiento de un árbol binario de búsqueda, organizando los empleados mediante su identificador y utilizando una interfaz gráfica para facilitar la interacción con sus operaciones.

# Tecnologías utilizadas
Java
Java Swing
NetBeans IDE
GitHub

# Características
Captura de los datos de los empleados: ID, nombre, puesto, departamento y salario.

Diseño de controles para agregar, buscar y eliminar empleados.

Opciones para mostrar los recorridos inorden, preorden y postorden.

Controles para calcular la amplitud y profundidad del árbol.

Opción para balancear y destruir el árbol.

Tabla para visualizar los datos de los empleados.

Área para mostrar resultados y mensajes.

Interfaz gráfica organizada mediante paneles.

# Estructura del proyecto
Clase Empleado: representa los datos de cada empleado, incluyendo su identificador, nombre, puesto, departamento y salario.

Clase NodoBST: almacena un empleado y las referencias a sus hijos izquierdo y derecho.

Clase ArbolBST: contiene las operaciones del árbol binario de búsqueda, como inserción, eliminación, búsqueda, recorridos, cálculo de amplitud y profundidad, balanceo y destrucción.

Interfaz gráfica: permite interactuar con las operaciones del árbol mediante formularios, botones, una tabla y un área de resultados.

# Interfaz gráfica
La interfaz se diseña en NetBeans mediante el editor visual GUI Builder y componentes de Java Swing. Su propósito es organizar los datos y las operaciones del árbol de una manera clara y sencilla.
